## 1. 项目目标

在当前工作区开发一个面向英语顾客的自托管电商站。先在本机开发和测试，再部署到 AWS。使用 WordPress/WooCommerce 管理商品和交易，通过自定义 Storefront 子主题实现品牌界面。

可参考 JuvaBun 的页面组织和购物体验，不复制其品牌、图片、文案和用户评价。参考网址只是设计背景，具体设计任务开始前再按需要查看。

## 4. 系统结构与代码交付

```text
本机浏览器
   -> Apache (127.0.0.1:8080)
   -> PHP / WordPress / WooCommerce
       -> MariaDB (127.0.0.1:3307)
       -> 本机上传文件

Git 管理：theme/、plugins/、scripts/、无密码配置示例、文档
本机持有：.local/ 中的运行程序、WordPress 副本、数据库、图片、日志与凭据
AWS 持有：正式数据库、上传文件、正式凭据、备份
```

后续主题源码目录为 `theme/`，自定义业务代码如有需要放 `plugins/`。WordPress/插件/父主题由官方发行包安装到 `.local/www/`，不得把整个运行目录提交 Git。正式数据迁移需单独设计，不能只复制源码或直接覆盖数据库。
